Users rarely notice good microcopy, but they notice bad microcopy immediately.

## Buttons

Name the action: "Get a quote", "Add to cart", "Publish post". The confirmation should use the same verb: "Published".

## Errors

| Bad | Better |
|---|---|
| Invalid input | Enter a 10-digit mobile number |
| Error 500 | Something went wrong on our side. Try again in a minute. |
| Field required | Add your email so we can reply |

## Empty states

Explain what will appear and offer one action: "No projects yet. Create your first project."

## Forms

Use visible labels, helpful hints and the right keyboard type on mobile.

## Consistency

Use the same word for the same thing everywhere. Your [brand voice](/blog/brand-voice-guide) still applies, adjusted for clarity.
