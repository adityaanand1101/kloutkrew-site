For most businesses, the majority of visitors arrive on phones. **Mobile-first design** makes sure the experience works there first.

## Principles

| Principle | In practice |
|---|---|
| Priority | Decide the one thing each screen must do |
| Thumb-friendly | Buttons large enough and within reach |
| Readable | Body text around 16px or larger |
| Short forms | Fewer fields, right keyboard types |
| Fast | Small images, minimal scripts |
| Simple navigation | Clear menu, sticky call to action where useful |

## Common mistakes

- Desktop layouts squeezed into a phone
- Pop-ups that cover the content
- Tiny text and links too close together
- Heavy video in the first screen

## Test on real phones

Emulators help, but test on mid-range Android phones on mobile data too.
