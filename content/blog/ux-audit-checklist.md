A **UX audit** finds the friction that quietly costs you enquiries, sign-ups and sales.

## Start with key journeys

List the three to five tasks that matter most, for example "find a service and enquire" or "add to cart and check out". Audit those first.

## The checklist

| Area | Check |
|---|---|
| First impression | Is it clear what this is and who it's for? |
| Navigation | Can users find key pages in two taps? |
| Content | Are headings scannable and specific? |
| Calls to action | Is the next step obvious on every page? |
| Forms | Short, labelled, clear errors? |
| Mobile | Thumb-friendly, readable, no horizontal scrolling? |
| Speed | Main content in under about 2.5 seconds? |
| Accessibility | Contrast, alt text, keyboard focus? |
| Trust | Reviews, real photos, contact details? |
| Analytics | Are key actions tracked? |

## Add evidence

Use analytics funnels, heatmaps and five short user tests to confirm what heuristics suggest. See [usability testing on a budget](/blog/usability-testing-on-a-budget).

## Prioritise

Score each issue by impact and effort. Fix high-impact, low-effort items first.
