Launching a site isn't the same as being found. Use this **SEO checklist** for any new website.

## Technical setup

- One primary domain; all others redirect to it
- HTTPS everywhere
- XML sitemap submitted in Google Search Console and Bing Webmaster Tools
- robots.txt allows crawling
- Canonical tags on every page
- Fast on mobile. See [Core Web Vitals](/blog/core-web-vitals-explained)

## On-page basics

| Element | Rule |
|---|---|
| Title tag | Service + place or benefit, under about 60 characters |
| Meta description | 140–160 characters, a reason to click |
| H1 | One per page, describes the page |
| Images | Descriptive alt text, compressed |
| Internal links | Link related pages and posts |

## Structured data

Organization or LocalBusiness, Service, Article, FAQPage and Breadcrumb schema where relevant.

## Local and off-page

- [Google Business Profile](/blog/google-business-profile-guide)
- Consistent name, phone and address on directories
- Reviews from real clients

## AI search

Clear facts about your business, FAQ-style answers and mentions on other sites help AI assistants recommend you. See [AI search visibility](/blog/ai-search-visibility-geo).

## Measure

GA4 with conversion events, Search Console and rank tracking.
