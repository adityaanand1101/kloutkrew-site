You've finished your logo, and the designer sends a folder full of files. Here's what each one is for.

## Vector vs raster

**Vector** files (SVG, PDF, EPS, AI) are made of shapes and scale to any size. **Raster** files (PNG, JPG, WebP) are made of pixels and blur when enlarged.

## The formats

| Format | Type | Use it for |
|---|---|---|
| SVG | Vector | Websites, apps, digital design |
| PDF | Vector | Print, sharing with printers |
| EPS / AI | Vector | Professional print and signage |
| PNG | Raster | Documents, slides, social, transparent backgrounds |
| JPG | Raster | Photos only; avoid for logos |
| ICO / favicon PNG | Raster | Browser tab icons |

## Common mistakes

- Using a screenshot of the logo
- Placing a JPG with a white box on a coloured background
- Sending a PNG to a signage printer
