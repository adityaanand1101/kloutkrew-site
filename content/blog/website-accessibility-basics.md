Accessibility makes your website usable for more people. Many fixes are simple and also improve SEO and conversions.

## Quick wins

| Area | What to do |
|---|---|
| Colour contrast | Text should contrast clearly with its background |
| Alt text | Describe meaningful images; leave decorative ones empty |
| Headings | One H1, then H2s and H3s in order |
| Link text | "See our packaging work", not "click here" |
| Forms | Visible labels, clear error messages |
| Keyboard | Every link and button reachable with Tab, with a visible focus outline |
| Motion | Respect "reduce motion" settings |
| Video | Captions for speech |

## Test it

Run Lighthouse's accessibility audit. On our own site, fixing labels and adding a main landmark took the home page from 88 to 97.
