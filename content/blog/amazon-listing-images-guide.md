On a marketplace, images do the selling. **Listing images** need to answer every question a shopper would ask in a store.

## A complete image set

| Slot | Shows |
|---|---|
| 1. Main image | Real pack on white, no extra text |
| 2. Key benefits | Three benefits with icons |
| 3. Ingredients / features | What's inside and why it matters |
| 4. Size and scale | Pack in hand or next to familiar objects |
| 5. How to use | Simple steps |
| 6. Lifestyle | Product in real life |
| 7. Comparison or range | Variants or why it beats alternatives |
| 8. Trust | Certifications, reviews, guarantees |

## Design tips

- Large, short text readable on a phone
- Consistent fonts and colours with your brand
- One message per image
- Real product photography where possible

## Thumbnails matter

The main image is often tiny in search results. Make sure the pack itself is designed for that. See [packaging for quick commerce](/blog/packaging-for-quick-commerce).
