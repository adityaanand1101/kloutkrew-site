As a product grows, screens drift: three button styles, five greys, inconsistent spacing. A **design system** fixes that and speeds everyone up.

## Start small

| Layer | Include first |
|---|---|
| Foundations | Colours, typography, spacing, grid, icons |
| Components | Buttons, inputs, selects, cards, modals, navigation |
| Patterns | Forms, empty states, errors, onboarding |
| Documentation | When to use each component, with examples |

## Make it practical

- Build components in your design tool and in code with matching names
- Document only what people actually use
- Assign an owner to approve changes

## Benefits

- Faster design and development
- Consistent experience
- Easier onboarding of new team members
- Built-in accessibility
